Сделай дизайн персонального сайта-портфолио в стиле Apple: строгий, профессиональный, много воздуха, крупная типографика.

**Кто:** Тамерлан Кобес — full-stack разработчик и студент. Язык макета — русский (сайт будет RU + EN).

**Стиль:**
- Как apple.com: светлый фон #fbfbfd, текст #1d1d1f, вторичный текст #6e6e73, акцент — синий #0071e3.
- Шрифт — системный SF Pro (крупные полужирные заголовки с плотным трекингом, spacing щедрый).
- Карточки: белые, скругление 24px, едва заметная тень и тонкая рамка #d2d2d7.
- Кнопки-таблетки (полностью скруглённые): основная — синяя заливка, вторичная — прозрачная с рамкой.
- Никаких градиентов, теней «в лоб» и декоративного шума. Сдержанно и дорого.

**Экраны/секции (один лендинг, desktop 1440px + мобильная версия 390px):**
1. **Шапка** — имя слева, справа навигация: Проекты · Стек · Обо мне · Контакты, переключатель RU/EN (маленькая таблетка).
2. **Hero** — «Привет, я / Тамерлан Кобес / Full-stack разработчик», подзаголовок: «Строю продукты полного цикла — от архитектуры и базы данных до запуска и первых пользователей», две кнопки: «Смотреть проекты» (синяя) и «Написать мне» (вторичная).
3. **Факты** — ряд из 4 небольших карточек-плиток: «Табыс — собственный B2B-продукт, запущен и работает», «CTO платформы KazTeenCommunity», «Хакатон AITK — 20 место из 72, соло», «Волонтёр UNICEF Kazakhstan».
4. **Проекты** — три карточки, первая широкая (на всю ширину, флагман):
   - **Табыс** (широкая) — B2B-платформа для продавцов Kaspi и Wildberries: радары ниш и цен, юнит-экономика, SEO-карточки на русском и казахском. Стек: TypeScript, Supabase, Edge Functions, Telegram Mini Apps, React 19, Gemini API.
   - **CareerVerse** — геймифицированная платформа развития карьеры (уровни, XP, адаптивные тесты). Стек: NestJS, Prisma, PostgreSQL, Supabase, Next.js. Ссылка «Код на GitHub →».
   - **KazTeenCommunity** — платформа профориентации для подростков Казахстана, роль CTO. Стек: React 18, TypeScript, Vite, shadcn/ui, Supabase.
   В каждой карточке: название, слоган синим, описание, 3–4 буллета с деталями, чипы технологий.
4. **Стек** — 4 колонки чипов: Языки / Frontend / Backend / Инструменты.
5. **Обо мне** — два абзаца текста, максимум 60 символов в строке.
6. **Контакты** — большая карточка с заголовком «Контакты», подзаголовком «Открыт к предложениям о стажировке и работе» и двумя кнопками: Почта и GitHub.
7. **Футер** — тонкая линия, «© 2026 Тамерлан Кобес».
